# ADR-003: Keep the handbook live with a passive map and content fingerprints

**Status:** proposed.
**Evidence basis:** competitor review, published agent evaluations, and maintainer goals.
**Deciders:** awaiting maintainer review.
**Supersedes in part:** [ADR-001](ADR-001.md), which excluded hooks and passive context.

## Context

Manual commands kept context small, but agents did not know the handbook existed.
Nothing detected drift after a commit unless the user supplied a base ref.
Vercel reported that a compact docs index in always-loaded instructions passed
100% of its evals, against 79% for on-demand skills.
That result covers one framework task, so treat it as a direction, not proof.

## Choice implemented

- Load a compact page map, limited to `contextBudget` bytes, at session start.
  For other agents, write the same map into a managed block in `AGENTS.md` or another file.
- Record content IDs of covered and linked files per page with `sync`.
  `status` compares them with current content, so committed changes count.
- Use a Stop hook that reminds once per stale set, or asks for update in `auto` mode.
- Make only `update` model-invocable. It still runs in an isolated task.
- Judge pages by the evidence they cite. A Python line-range link fingerprints the
  enclosing function or class syntax tree. Other files use normalized text.
  Changes elsewhere in covered files only mark the page for review.
- Point the agent to a file's page when it opens that file, once per page per session.
- Keep the committed `contextFile` block free of stale flags, which go out of date between commits.

| Alternative | Benefit | Cost |
|---|---|---|
| Manual commands only (ADR-001) | No passive context | Agents ignore the handbook; drift goes unnoticed |
| Whole handbook in instructions | Maximum recall | Large fixed cost on every turn |
| Update agent after every edit | Always current | Model cost every turn; churn during unfinished work |
| Passive map, evidence fingerprints, reminders | Small fixed cost; drift is explicit and precise | Pages without line-range evidence fall back to file-level flags |

## Consequences

Every session in an opted-in project pays for the map, about 300 to 750 tokens by default.
Projects without a handbook pay nothing. The hooks need Python 3.9+ on `PATH` as `python3`.
Agents must sync only pages they reviewed. A careless `sync --all` hides drift.

## Validation and review trigger

[Freshness and hook tests](../../../tests/test_archlens.py#L431-L567) and the
[benchmarks](../../benchmarks.md) cover behavior and cost.
Revisit if measured answer quality does not improve, or the map costs more than it saves.
