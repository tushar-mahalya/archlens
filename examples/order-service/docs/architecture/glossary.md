# Glossary

| Term | Meaning in this example |
|---|---|
| Request key | Caller-supplied value that identifies one intended order |
| SKU | Product identifier supplied by the caller |
| Transaction | A group of database operations that commit or roll back together |
| Idempotent submission | A matching repeated submission returns the same stored order ID |
| Conflict | A request key is reused with different order data |

These are local project definitions, not an official STE vocabulary.
