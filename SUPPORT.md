# Support

## Get help

- **Questions, ideas, and examples:** use [GitHub Discussions](https://github.com/tushar-mahalya/archlens/discussions).
  Choose *Q&A* for usage questions and *Ideas* for proposals.
- **Bugs:** open a [bug report](https://github.com/tushar-mahalya/archlens/issues/new?template=bug_report.yml).
  Include the distribution, agent host, Archlens version, and the exact steps.
- **Security issues:** do not use a public issue. Follow [SECURITY.md](SECURITY.md).

## Before you ask

1. Read the [README](README.md) and the [installation guide](docs/installation.md).
2. Run the checker on your handbook: `python <skill-or-plugin-dir>/scripts/archlens.py check --root . --strict`.
3. Search existing issues and discussions.

## Expectations

Archlens is maintained by volunteers. There is no guaranteed response time.
Only the latest release receives fixes.
